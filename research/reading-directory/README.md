# Inner Compass Suggested Reads Directory

A static, auditable visual reading directory linked to the Wisdom Corpus and 25-category taxonomy.

## Product rules
- Distinguish philosophy, religion, metaphysics, ethics, contemplative practice, and scholarship.
- Do not collapse Asian traditions into generic "Eastern wisdom."
- Primary texts, scholarship, and modern introductions are visibly labeled.
- Every card has a legal source link and visual provenance state.
- When no legally approved cover is bundled, the UI renders an original designed fallback cover instead of scraping copyrighted art.
- No runtime AI is required for search, filtering, pathways, or recommendations.

## Files
- `traditions.json` — tradition hierarchy
- `readings.json` — audited starter directory
- `reading-pathways.json` — curated static pathways
- `category-reading-map.json` — taxonomy links
- `schemas/reading.schema.json` — data contract
- `translation-guide.md` — translation/edition guidance
- `rights-review.md` — visual/text rights rules

The initial directory is intentionally a high-quality starter collection rather than an indiscriminate catalog.
