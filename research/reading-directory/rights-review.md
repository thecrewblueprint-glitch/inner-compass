# Reading Directory Rights Review

## Text links
The directory links to legal public-domain/open-access hosts when available. It does not host copyrighted books.

## Cover images
The first release does **not** scrape commercial cover art. Each record includes cover provenance metadata. When `cover_image_url` is null, the product renders an original metadata-driven cover design.

Allowed future image states:
- PUBLIC_DOMAIN
- OPEN_LICENSE
- LICENSED_OR_PERMISSIONED
- OFFICIAL_REMOTE_THUMBNAIL_REVIEWED
- GENERATED_FALLBACK

A remote thumbnail must not be added merely because an image URL exists; provenance and product-display rights must be reviewed first.

## Websites
Website/resource cards use product-generated visual treatments. Third-party logos or hero images are optional and require rights review.
