# Legal Page Audit — 2026-09-20

## Pages/surfaces

- Terms of Use
- Privacy Notice

- Safety & Crisis Notice

## Audit criteria

- [x] General-wellness positioning; no diagnosis/treatment claim.
- [x] Local-only raw reflection architecture disclosed.
- [x] No-sale/no-targeted-advertising current-state claim matches code policy.
- [x] Local diagnostics disclosed and raw-text exclusion stated.
- [x] Separate consumer-health-data policy exists.
- [x] Safety detection limitation disclosed; no false guarantee of perfect language recognition.
- [x] Lifelines are directly accessible.
- [x] English-only safety scope is stated.
- [x] WCAG 2.2 AA is a target, not self-certified compliance.
- [x] Public operator/contact values are not fabricated.
- [x] Terms/Privacy are explicitly marked controlled-beta drafts until counsel/owner gates are complete.
