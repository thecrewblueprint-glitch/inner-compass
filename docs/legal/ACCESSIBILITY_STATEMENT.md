# Inner Compass Accessibility Statement

Inner Compass aims to provide an experience usable with keyboards, screen readers, zoom, high-contrast themes, and mobile devices.

## Engineering target

The current engineering target is **WCAG 2.2 Level AA**.

Automated accessibility checks are treated as smoke tests only. They do not replace a manual WCAG 2.2 AA review before public launch.

## Current scope

- Web application
- Desktop and mobile viewport testing
- English-only content at this release stage

## Public-launch requirement

A public accessibility contact/feedback channel and a completed manual accessibility review remain required before public launch.

Reference:
https://www.w3.org/TR/WCAG22/
